Five ways

Things one person can now build alone.

Each of these used to need a team, a budget, or somebody's permission. None of them do now.

Software for one user

Nobody funds an app with a market of one. So build it yourself. A tracker shaped like your workflow, a script watching one page.

Domain knowledge plus execution

Ten years in an industry teaches you which process is broken. Now you can fix it yourself, without pitching someone who won't get it.

Physical prototyping

CAD, simulation, firmware and datasheets used to be four specialists. One person can go from idea to a file a factory can run.

Independent research

Read across thousands of papers. Test a hypothesis with no institution behind you. Rare disease parent groups already found real things this way.

One-person media

Write, direct, score, cut, distribute. Formats that needed a crew now need one person with taste and stamina.

Whatever you add next

The list keeps growing. Every month somebody does a thing that needed a company last year.
